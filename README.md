# 📌 Proyecto: Resolución de Ecuaciones en C#

Este proyecto es una aplicación desarrollada en **C#** que permite resolver diferentes tipos de ecuaciones matemáticas, incluyendo ecuaciones de primer y segundo grado, además de generar sus respectivas gráficas.

---

## 🚀 Características

* ✅ Resolución de ecuaciones de **primer grado**
* ✅ Resolución de ecuaciones de **segundo grado**
* 📊 Generación de gráficas para visualizar las soluciones
* 🧮 Cálculo automático de raíces
* 💡 Interfaz simple y fácil de usar

---

## 🛠️ Tecnologías utilizadas

* **Lenguaje:** C#
* **Framework:** .NET
* **Gráficas:** (Windows Forms)

## ▶️ Cómo ejecutar

1. Clona este repositorio:

   ```bash
   git clone https://github.com/Physanto/SolveEquations.git
   ```

2. Abre el proyecto en Visual Studio o tu IDE favorito.

3. Compila y ejecuta el proyecto.

---

## 📈 Ejemplo de uso

* Ingresar una ecuación como:

  * `2x + 4 = 0`
  * `x^2 - 5x + 6 = 0`

* El programa calculará:

  * Las soluciones
  * Mostrará la gráfica correspondiente
